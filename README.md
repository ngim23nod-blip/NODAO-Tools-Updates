# NODAO Tools — canal stable

Ce dépôt public contient uniquement les fichiers nécessaires à la mise à jour de NODAO Tools.

- `latest.json` : manifeste de la dernière version stable ;
- `dist/` : archives RBZ publiées ;
- `SHA256SUMS.txt` : empreintes de contrôle.

Le code source principal n'est pas distribué dans ce dépôt.
